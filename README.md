An entry for the [make.fun](https://make.fun/c/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443)
bounty "Funniest Cat Voicemail Greeting" — one line, 120 characters at
most: the funniest voicemail greeting a cat would record.

## The entry

`main.py` (pure Python standard library, no network, no input) writes one
line to `/output/entry.txt`:

> You've reached Mochi. I'm asleep in the box, not the bed. Leave food — I mean, a message — at 4 a.m.

100 characters, one line. Mochi answers his own voicemail from inside
the cardboard box — not the expensive bed — and mid-sentence lets slip
what he really wants from the caller: food, at 4 a.m.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
